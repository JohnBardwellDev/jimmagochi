# Jimmagochi

A small virtual pet app built in React. Meet Jimothy the raccoon: feed him and pet him to fill up his hunger and happiness bars.

Built as a week 2 team project at Dev Academy Aotearoa. I worked on the CSS and UI.

## Features
- Feed and Pet buttons that raise Jimothy's hunger and happiness stats
- Jimothy's image changes as he eats or gets happy, and he grows a little with every meal
- Burger and heart confetti bursts (canvas-confetti)
- Falling leaves animation over a forest background
- Reset button to start over

## Tech
React · TypeScript · Vite · CSS · canvas-confetti

## Run it locally
```
npm install
npm run dev
```
Then open http://localhost:5173.
